# Test sites (Gitea-only)

`elementor-sites.txt` — list of real live Elementor sites used by
`tools/survey-coverage.js` to measure real-world coverage.

Kept on this branch in Gitea (private), **not** published to the public
GitHub repo (the public README explains the methodology + the 60–83% band
without shipping the scraped third-party domain list).

Run:  `node tools/survey-coverage.js --sites tools/data/elementor-sites.txt`
